# betterrooster
RUG schedule viewer, with more advanced and convenient functionality
Live webpage: https://betterrooster.onrender.com/
General instruction:
Add your courses/programmes and select your tutorial group on the right.
Click generate schedule
You may save your current filters via save button andd 
___________________________________________________________________

It is recommended to launch server locally to do so:
1.Install python
2.Download launch.py from this github repo
3.Either doubleclick on a launch.py(not recommended) or open cmd and write "python launch.py"
(A new window in your browser should open)
*4.In case terminal didnt open you will have to kill the local server through task manager if you need to do so
