# betterrooster
RUG schedule viewer, with more advanced and convenient functionality
**Live web page:** <https://betterrooster.onrender.com/>

## General instructions

1. Add your courses/programmes and select your tutorial group on the right.
2. Click **Generate schedule**.
3. You may save your current filters via the **Save** button.
4. and load them later from the top of the page

---

## Running locally

It is recommended to launch the server locally to do so:

1. Install Python.
2. Download `launch.py` from this GitHub repo.
3. Either double-click on `launch.py` (not recommended) or open `cmd` and write
   `python launch.py`
   (A new window in your browser should open).
4. _In case the terminal didn't open, you will have to kill the local server
   through the Task Manager if you need to do so._
